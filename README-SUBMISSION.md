This submission investigated and fixed all seven intentional EU Pay defects across payments, authentication, webhooks, table orders, and e-invoicing. The implementation preserves the existing endpoint contracts, adds HMAC verification and idempotency, and makes the in-memory test setup repeatable without requiring a manually running server. The Node.js test suite contains 21 focused tests covering happy paths, validation boundaries, authentication, security, persistence, and duplicate requests. Findings, fixes, and the webhook test strategy are documented in `bug-reports.md`, `fixes.md`, and `test-plan.md`.
